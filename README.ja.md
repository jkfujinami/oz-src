## 主な機能

- **ブラウザ内オニオンルーティング**<br>
  通信データは、WebRTC ピアから選ばれた Guard と、その先の中継ノードを経由する 2 ホップ構成。各ホップで階層的に暗号化されます。ペイロードは 1,200 バイトの固定長セルに分割され、常時流れるカバートラフィック（ダミーセル）に紛れて配送。Guard は実際の送信タイミングを特定できず、中継ノードにも送信者の IP アドレスは伝わりません。
- **全員参加型の相互リレー**<br>
  有志による固定の出口ノード運営に依存しません。起動中のタブやアプリ同士が、互いのセルを対等に中継し合います。
- **発信元を隠蔽するメッセージ配送**<br>
  投稿メッセージは中継ノードを抜けた後、Dandelion++ 方式に基づくランダムウォークを経てからネットワーク全体へ伝播します。
- **匿名掲示板**<br>
  誰でも閲覧できる公開板と、共有コードでアクセスする非公開板に対応。スレッドごとに独立した署名鍵を生成するため、複数スレッドを横断した投稿者の紐付けを防ぎます。
- **専用サーバー不要の大容量ファイル共有（Ozzy）**<br>
  ファイル全体を暗号化した上で、Reed-Solomon 符号化により 32 個のシャードへ分散（うち任意の 16 個で復元可能）。無料のパブリックストレージへ分散配置されます。アップロードおよびダウンロード処理は、参加者各自が運用する Cloudflare Worker を介して中継ノードが代行するため、ホスティング先や中継ノードに自身の IP アドレスは露出しません。
- **アカウント不要の耐DoS・耐スパム設計**<br>
  ノード ID の生成には Argon2id、投稿にはペイロードサイズに応じた Equi-X による Proof of Work（計算量証明）を要求。中央集権的なアカウント管理なしに不正利用を抑止します。
- **ローカルデータの暗号化と緊急消去**<br>
  閲覧・投稿履歴や秘密鍵はパスフレーズで暗号化して保存。ワンタッチで画面を隠すロック機能や、全データを瞬時に消去する緊急ワイプボタンを備えています。

## 脅威モデルと限界（防げない攻撃）

- **グローバルな受動的攻撃者：** インターネット全域を広範に監視できる組織によるトラフィック解析は防げません。
- **Guard と中継ノードの結託：** Tor の 2 ホップ設計と同様、経路上にある全ノードが結託した場合は追跡を受けるリスクがあります（信頼 Guard の指定によりこの確率を下げられます）。
- **OZ 利用事実の検知：** 直接接続する Guard およびシグナリング用のトラッカーには自身の IP アドレスが見えるため、OZ を使っている事実そのものは隠蔽できません（トラッカーは WebRTC ピアの紹介のみを担当します）。
- **Cloudflare への依存：** リレー用の Worker は Cloudflare 上で稼働します。Cloudflare 側に見えるのは中継ノードと外部ストレージの URL のみですが、特定インフラへの依存が存在します。
- **外部ホスティングによるファイル削除：** 保存先サービスの都合でシャードが削除される可能性があります。各ストライプのシャードが半数まで失われてもファイル自体は再構築できます。

## ダウンロード

macOS・Windows・Linux 向けのインストーラーを [Releases](https://github.com/jkfujinami/Oz/releases) で配布しています。整合性検証用の `SHA256SUMS.txt` も同ページで確認できます。

開発者アカウント（Apple / Microsoft）と現実の身元が紐づくのを避けるため、**バイナリへのコード署名は施していません**。初回起動時は以下の手順を実行してください。

- **macOS：** 「アプリケーション」フォルダに配置後、一度開こうとして警告を閉じ、「システム設定」→「プライバシーとセキュリティ」→「このまま開く」を選択。macOS 14 以前は、右クリック（または Control + クリック）から「開く」を選択。
- **Windows：** SmartScreen の警告画面で「詳細情報」→「実行」を選択。
- **Linux：** `chmod +x OZ-*.AppImage` を実行して起動。

デスクトップ版では、自身のマシンを他ユーザーのための **Guard** として稼働させることも可能です（「設定」→「この端末の Guard」）。Guard は専用の ID でバックグラウンド常駐し、画面をロックした状態でも中継処理を継続します。

## 信頼 Guard

第 1 ホップとなる Guard にはクライアントの IP アドレスが見えるため、OZ はメンテナーが署名したリストに載っている Guard を優先的に利用します。メンテナーの公開鍵は [`trust/trust.json`](trust/trust.json) に内蔵されています。署名済みリストが提供されるまでの間は、オープンネットワーク上の Guard から自動選択されます。Guard をリストに登録する手順は [`trust/README.md`](trust/README.md) を参照してください。

## リポジトリ構成

| パス | 内容 |
| --- | --- |
| `packages/core` | プロトコル基盤（ノード ID、WebRTC メッシュ、オニオンルーティング、掲示板、Ozzy） |
| `packages/ui` | Web 版・デスクトップ版共通の UI コンポーネント（React） |
| `packages/tracker` | ピア同士を接続するシグナリングトラッカー（Node.js / Deno Deploy） |
| `packages/r2-worker` | ファイル中継用の Cloudflare Worker |
| `apps/desktop` | デスクトップアプリ（Electron） |
| `apps/guard` | ヘッドレスで動作する Guard 専用プロセス |
| `web` | Web 版クライアント（Next.js による静的エクスポート） |
| `trust` | ビルド時に同梱するメンテナー公開鍵および署名済み Guard リスト |

## ビルド手順

動作には Node.js 22 以上が必要です。

```sh
npm ci
npm run build:core

# デスクトップ版（apps/desktop/release/ に出力）
npm run build:desktop
cd apps/desktop && npx electron-builder --mac --win --linux --publish never

# Web 版（web/out/ に出力）
npm run build:web

# テスト実行
npm test
```

リリースバイナリは、メンテナー環境で [`scripts/release.sh`](scripts/release.sh) を実行して生成し、[jkfujinami/Oz](https://github.com/jkfujinami/Oz/releases) で公開しています。利用規約のマスターテキストは `packages/ui/src/lib/terms.ts` です。規約文面を変更した際は `npm run terms` で `TERMS.md` を再生成してください。
